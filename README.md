# QUIZINOX v2.5.0 — Offline + Online Quiz App (Android + Windows)

Local-first quiz maker/player built from the QUIZ-BOT engines. Works fully offline;
AI features use the internet only when you start them.

## Features
**Offline (no internet needed)**
- Create, edit, duplicate, delete quizzes · bulk-paste questions
- Exam mode: **Previous / Next**, **question palette** (jump to any question), mark for review, clear response, per-question timer, submit with unanswered warning
- Practice mode: instant correct answer + explanation, free navigation
- Unfinished attempts are saved — resume from the dashboard
- Results with filters (correct / wrong / unanswered), "Practise mistakes" quiz, PDF report
- Import TXT / JSON / PDF · Export JSON / TXT (😂 format) / PDF question paper
- **Coaching PDF → TXT converter**: Any PDF (auto), ForumIAS SFG, Vajiram & Ravi, VisionIAS, PW Only IAS and ForumIAS 100 (original supplied suite included)
- TXT fixer + 😂 emoji formatter (ports of the bot's txtfixer)
- Backup / restore (merge or replace) · analytics with score trend

**Online (optional, your own Gemini key)**
- AI question generator from a topic or from your notes / PDF (English / Hindi / bilingual)
- Online bulk quiz translation into 100+ Indian and world languages (question, options and explanations); switch language during a live attempt without changing answer indexes\n- Result exports: playable HTML quiz, Test PDF, Solution PDF, merged Test+Solution PDF, Study Notes HTML and print-to-PDF Notes in original or translated language\n- Original supplied Quiz Maker, Test Series Maker, Notes Generator and TXT/PDF Translator are bundled under File Studio / result exports and prefilled with the selected quiz where supported
- Topbar shows ONLINE / OFFLINE status live

## Build the APK (GitHub)
1. `python -m pip install requests`
2. `python upload_to_github.py` → enter repo name, username and a GitHub token (repo + workflow scope)
3. The script uploads the code, waits for **Actions → Build QUIZINOX Android APK** and downloads `QUIZINOX.apk` next to itself.

Or push this folder to GitHub manually and download the `QUIZINOX-APK` artifact from Actions.

## App icon
`assets/quizinox-icon.png` is the source. During the build, `scripts/generate_android_icons.py`
removes Capacitor's default launcher icon (the vector in `drawable-v24` that previously hid the
custom icon) and writes QUIZINOX icons for every density, the adaptive icon and the splash screen.
To change the icon, replace `assets/quizinox-icon.png` (square PNG, 1024x1024) and rebuild.

## QUIZINOX 2.1 additions
- PW Only IAS and ForumIAS PDF conversion are available in the bundled original coaching converter suite. TXT downloads are passed back to QUIZINOX for direct quiz import.
- The translation engine uses the same public Google Translate endpoint approach as the supplied translator. It is online-only and may be temporarily rate-limited; translation quality and availability are not guaranteed.

## Version 2.4.0 — Windows desktop + per-attempt shuffle

### Windows desktop app
- QUIZINOX now has an Electron desktop wrapper and can be installed as a normal Windows application.
- The NSIS installer creates Start Menu and Desktop shortcuts, supports a custom install folder, and keeps app data when the app is uninstalled.
- Quiz data is stored in the Windows app's local profile and stays on that laptop. The app works offline for local quiz creation, attempts, review and file tools.
- Downloads are saved in the Windows Downloads folder.

**Build the Windows installer on Windows:** install Node.js 22 LTS, extract this project, open PowerShell in the `QUIZINOX` folder, then run:

```powershell
npm install
npm run desktop:dist
```

The installer will be created in `release/QUIZINOX-Setup-2.4.0.exe`. For a no-install portable executable, run `npm run desktop:portable`; it will be placed in `release/`.

**Build without setting up Node locally:** push this project to GitHub, open **Actions → Build QUIZINOX Windows Installer → Run workflow**, and download the `QUIZINOX-Windows-Installer` artifact after it finishes. No API key or environment variable is needed.

### Shuffle on every attempt
- Every time a quiz starts, in either Exam or Practice mode, QUIZINOX asks: Only questions, Only options, Both, or No shuffle.
- Question and option arrangements are freshly randomised. Correct answers remain correctly mapped after option shuffling.
- Recent arrangements are recorded per quiz and shuffle mode to avoid repeating an arrangement. If a quiz has only a small finite number of possible arrangements and all have been used, a repeat is mathematically unavoidable; the app displays a notice when it reaches that point.

### One-click GitHub Windows build (new in this package)
- Run `RUN-WINDOWS-BUILD.bat` on Windows, or execute `python BUILD-WINDOWS-VIA-GITHUB.py` from this folder.
- Enter your GitHub username and PAT when prompted. The PAT is hidden while typing and is not stored in the project.
- The script creates/reuses a GitHub repository, pushes the source, waits for the Windows GitHub Actions build, downloads the installer, and creates `QUIZINOX_v2.4_Windows_Complete.zip` in the parent folder with the `.exe` inside `release/`.
- Requires Python 3.9+, Git for Windows, internet access, and a PAT with repository and Actions access. A classic PAT with `repo` + `workflow` scopes is the simplest option; creating a new repository also requires permission to create repositories on the account.
- Full instructions: `BUILD-WINDOWS-AUTOMATICALLY.md`.


## Version 2.5.0 — Smart study update

### 1. Smart question navigation
- **Swipe** left / right on the question card (phone) to go to the next / previous question.
- **Keyboard shortcuts** (Windows): ← → move · Enter/Space next · 1–8 or A–E choose option · X clear · M mark for review · F bookmark difficult · G jump to number · U next unanswered · Home/End first/last · T palette · L language · I ask AI · S submit · Esc exit · ? help (⌨ button in the quiz).
- **Jump** to any question: palette numbers, "Go to Q#" box, "Next blank" button or the G key.
- **Bookmark difficult questions** (⚐) while playing, in results, revision and search.
- **Resume** an unfinished quiz from the exact question you left (Home banner or Play → "Resume from Q…").

### 2. Detailed performance analytics
- Per attempt: accuracy %, correct / incorrect / skipped, average time per question, fastest & slowest questions, topic-wise table, full negative-marking calculation (and a "with −⅓" comparison when the quiz has no negative marking).
- Analytics page: overall accuracy, avg time (correct vs wrong), rushed mistakes, subject-wise and topic-wise tables, fastest/slowest questions, negative-marking calculator.
- Add a **Topic** to each question in the quiz editor (AI-generated questions get topics automatically).

### 3. Automatic revision system
- Wrong answers enter the revision list automatically. Bookmarked difficult questions are also saved separately.
- Each question returns after **1, 3, 7 and 15 days**. Correct on time → next step; wrong → back to Day 1; it leaves revision only after a correct recall at the 15-day step ("mastered").

### 4. Question search
- Search all quizzes by keyword or "exact phrase" — question, options, explanation, topic, and translated versions. Turn the results into a practice quiz.

### 5. Multi-language mode
- In a quiz tap 🌐: show **one language** (e.g. only Hindi) or **bilingual / multilingual** (2–3 languages together, e.g. Original + Hindi). One tap switches back to one language. Default preference in Settings.

### 6. AI (optional, online, free Gemini keys)
- **AI Personal Study Analyst**: runs only when you tap "Analyse with AI" (1 request). Weak subjects, repeated mistakes, accuracy & speed insights and a 7-day plan. Offline insights are always shown without AI. Daily run limit is configurable (default 5/day).
- **Ask AI – Question Tutor**: why the answer is correct, why the others are wrong, simple explanation, what else to read for UPSC, 2 similar MCQs, or your own doubt. Answers are cached on the device so repeating a question costs nothing. "Add to explanation" saves the AI note into the quiz.
- **AI Question Generator**: from a topic, PDF/TXT, pasted notes or your weak topics. Types: standard MCQ, statement-based, match the following, assertion–reason, multiple correct answers, pairs, chronology. Choose difficulty, exam style, language (English / Hindi / bilingual), explanation depth, preview & select before saving, add to an existing quiz, stop anytime and keep partial results. Long PDFs are split into parts so each request stays small.
- **Multiple API keys with automatic failover**: add any number of Gemini keys in Settings → AI keys (or paste many at once). If a key is invalid, rate-limited or out of daily quota, the next key is used automatically. If every key is busy on one model, QUIZINOX falls back to another free model (2.5 Flash → 2.5 Flash-Lite → 2.0 Flash → 2.0 Flash-Lite).
- **Free-tier guard**: requests are paced per key and per model at 80% of Google's published free limits; daily limits reset at midnight Pacific time. Keys from the *same* Google Cloud project share one quota — use keys from different accounts/projects for more capacity. Keys are never included in backups.
